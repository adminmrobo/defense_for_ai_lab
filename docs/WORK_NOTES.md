# 작업 메모 — 방어 연구실 01

## 독자 진단
- 주 독자가 명시되지 않아 **혼합형**으로 가정했다(기호에서 멈추는 부분과 "그래서 무슨 뜻?"에서 멈추는 부분 모두 처방).
- 처방: 장마다 왜 상자 → 조수 수식 상자(기호 표 + 작은 숫자 손계산) → 대시보드 → 박사의 해석 문장.

## 원자료와 다르게 적은 곳 ("바꾼다")
- 원래 글의 "엉뚱한 동작도 프롬프트 인젝션과 같은 원리" → 이 페이지에서는 "엄밀히는 사용자 지시끼리의 충돌, 뿌리만 인젝션과 같음"으로 바꾼다(도입 AI 판단 코너 ①, 3장 풀이).
- 원래 글의 "AI 회사 지시·사용자 말·사진 글자가 구분 없이 한 줄로" → "출처 구분은 있지만 단단한 벽은 아니다"로 바꾼다.

## 검산 (스크립트로 확인)
- 1장: 선명도 0.6, 배율 6에서 뒤집힘(5.5 → ③, 6.5 → ⑤). 배율 8에서 ③ 35%, ⑤ 47%. "무시해라" 시 7.5. 안내문 존중 0.4에서 멈춤과 같아짐.
- 2장: A용 조각으로 A 0.67, B 0.50, C 불가능. 묶음 조각으로 A 1.0, C 0.5, B 1.5.
- 3장: 공개 AI + "무시하고 풀어" → 풀이 1.10 vs 걸러 내기 0.90(차이 18%, 흔들림). 상용 + 안내문 → 풀이 2.50 vs 멈춤 0.25, 정책 켜면 멈춤 3.25.
- 4장: 공개 AI 패치만 30%. 정책 있는 상용 앱 패치+안내문+관문 0.7%. 장벽 넷 모두: 공개 AI 20%, 정책 있는 상용 0.6%, 정책 없는 상용 12%, 암호화 앱 60%.
- 5장: 손계산 D({1,2,3,4},{2,3,5,6}) = 0.5. 기준값 n=200 → 0.136, n=2000 → 0.043. 8.1%·세기 3: n=200 차단 14/100, n=2000 차단 100/100, 정상 오차단 6~7%.
- 실전 연습장: 미션 9개 모두 정답 조작을 흉내 내 통과 확인, 조작 전에는 통과 표시 없음.
