# 방어 연구실 01 — AI의 추론을 방해하는 것은 나쁜가?

> AI 추론 장벽 찬반 토론 · 초파리 연구실 해설 페이지

시험지 패치, 숨은 지시(프롬프트 인젝션), 네트워크 관문으로 AI의 추론에 **장벽**을 세우면 정답률이 떨어집니다. 이 페이지는 그 원리를 **베이즈 정리**(확신이 옮겨 가는 계산)와 **적대적 예제**(판단 경계 너머로 미는 작은 변화)로 풀고, 같은 기법이 공격인지 방어인지를 연구실 식구들의 **찬반 토론**으로 따져 봅니다. 장마다 직접 만지는 대시보드가 있습니다.

- 사회: 박사
- 찬성(방해도 방어가 될 수 있다): 인턴1 시아 · 인턴2 모아 · 조수 하루 · 주판봇
- 반대(방해는 신뢰를 무너뜨린다): 초파리 연구원 · X1 · X2 · X3
